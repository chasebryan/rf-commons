# RF Commons Vision

RF Commons is a public-good radio infrastructure project.

It is not just a single app. It is a shared workbench for people learning,
listening, mapping, documenting, and responsibly exploring public radio signals.

## Product Shape

```text
Listen -> tune, demodulate, hear signals
Learn  -> understand what signals are and how SDR works
Map    -> browse public receivers, bands, and radio activity
```

## Principles

- Open radio for everyone.
- No ads.
- No telemetry.
- No account required.
- Local-first where possible.
- Receive-only until safety, licensing, and operator intent are explicit.
- Public knowledge without private-signal harvesting.
- Useful to learners, amateur radio operators, schools, clubs, and emergency-prep groups.

## First Useful Layer

The missing layer in SDR software is not another receiver window. It is the
bridge between a waterfall and understanding:

```text
What am I looking at?
```

RF Commons should turn observations into useful next steps:

```text
Likely signal: Narrowband FM voice
Common use: amateur / local repeater / utility
Bandwidth: ~12.5 kHz
Demodulation: NFM
Suggested next step: try squelch + audio decode
```

That keeps the project practical while still serving the larger commons mission.
